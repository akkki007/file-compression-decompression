Crow internally uses:

```
ASIO → networking
Boost → threading & utilities
pthread → multithreading
```

So the required dependencies are:

```
libboost-all-dev
libasio-dev
libssl-dev (optional for HTTPS)
```

Install everything once:

```bash
sudo apt install libboost-all-dev libasio-dev libssl-dev
```

## Fix: Docker Repo Architecture Warning

This warning appears because your Docker repository is configured to fetch packages for **both `amd64` and `i386`** architectures, but Docker's repo only supports `amd64`.

### Step-by-Step Fix

**1. Find the Docker source file:**
```bash
ls /etc/apt/sources.list.d/ | grep docker
```

**2. Open the file (usually named `docker.list`):**
```bash
sudo nano /etc/apt/sources.list.d/docker.list
```

**3. You'll see something like this inside:**
```
deb [arch=amd64,i386 signed-by=...] https://download.docker.com/linux/ubuntu noble stable
```
or it may have no `arch=` at all.

**4. Change it to explicitly set only `amd64`:**
```
deb [arch=amd64 signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu noble stable
```
> Just make sure `arch=amd64` is the only architecture listed.

**5. Save and exit:** `Ctrl+O` → `Enter` → `Ctrl+X`

**6. Run update again to confirm the warning is gone:**
```bash
sudo apt update
```

---

### Why This Happens
When APT has multi-architecture support enabled (common on 64-bit systems that once ran 32-bit apps), it tries to fetch package lists for **all enabled architectures** from every repo — even ones that don't support them. Pinning the Docker repo to `arch=amd64` prevents this.
